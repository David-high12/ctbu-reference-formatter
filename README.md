# 参考文献整理

面向重庆工商大学本科论文的参考文献整理试用版。选择一份 .docx，整理文末参考文献，再下载 Word 副本。论文在浏览器本地处理。

## 使用

1. 下载 dist/index.html 并用浏览器打开。
2. 选择论文，点击「整理参考文献」。
3. 核对待复核条目，下载 Word 副本。

首版按学院样例处理可识别的期刊 [J] 和学位论文 [D]。会议论文 [C]、部分英文作者缩写和结构不明确的条目会保留原文并提示复核。提交论文时请以学院当届模板为准。

## 源码

src/ 包含页面、文献规则和 Word 读写逻辑。在 PowerShell 内运行 build.ps1 可重新生成 dist/index.html。

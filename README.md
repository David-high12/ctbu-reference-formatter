# 参考文献整理

面向重庆工商大学人工智能学院本科论文。选择一份 .docx，整理文末参考文献，再下载 Word 副本。论文在浏览器本地处理。

## 使用

1. 下载 dist/index.html 并用浏览器打开。
2. 选择论文，点击「整理参考文献」。
3. 核对待复核条目，下载 Word 副本。

## 2026 版整理范围

- 依据学院 2026 版《本科生毕业论文（设计）文档规范化要求》，将参考文献标题设为四号黑体居中，条目设为小四仿宋、左对齐。
- 支持期刊 [J]、会议论文 [C]、图书 [M] 和学位论文 [D]，兼容 Word 自动编号、手打方括号编号及英文作者缩写。
- 保留原有编号和顺序。字段缺失或结构不明确的条目保留文本并提示复核。交稿前请核对文献内容和正文引用顺序。

## 源码

src/ 包含页面、文献规则和 Word 读写逻辑。在 PowerShell 内运行 build.ps1 可重新生成 dist/index.html。
